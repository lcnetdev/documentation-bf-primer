# RDF in BIBFRAME

The BIBFRAME vocabulary consists of RDF classes and properties. Classes include the core classes listed above (Work and Instance), important adjuncts (Item and Hub), and their subclasses. Properties describe characteristics of the resource as well as relationships between resources. For example, one Work might be an “expression of” a Hub; an Instance may be an “instance of” a Work.

Other properties describe attributes – for example, the BIBFRAME “subject” property expresses an attribute of a Work (what it is about), and the property “dimensions” expresses an attribute of an Instance.
